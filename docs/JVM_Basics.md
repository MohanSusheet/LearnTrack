# JVM Basics – LearnTrack Project

## 1. JDK, JRE, JVM

### JVM (Java Virtual Machine)

JVM is a virtual machine that runs Java programs.  
It takes the compiled Java code (bytecode) and converts it into machine code so that it can be executed on a specific system.

#### In simple terms:  
**JVM is responsible for running your Java program.**

---

### JRE (Java Runtime Environment)

JRE provides the environment required to run Java programs.  
It includes:

- JVM (to execute the program)
- Libraries and supporting files

#### In simple terms:  
**JRE = JVM + required libraries to run Java programs**

---

### JDK (Java Development Kit)

JDK is a complete package used to develop Java applications.  
It includes:

- JRE (to run programs)
- Compiler (`javac`) to convert code into bytecode
- Development tools

#### In simple terms:  
**JDK = JRE + development tools**
